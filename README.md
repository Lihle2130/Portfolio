# 2. Project Overview

UniMarket was developed as part of the Professional Practice Framework (PFP) module. The project aimed to address a common challenge experienced by students: the affordability and accessibility of academic resources.

The team proposed a digital marketplace where students could buy, sell and exchange second-hand textbooks, study guides, calculators, notes and other educational materials. The objective was to create a cost-effective solution that would help students access academic resources while allowing others to sell or exchange materials they no longer needed.

The project provided an opportunity to apply software development principles, collaborate as a team and practise Agile project management. Trello was used for Product Backlog management, sprint planning, task tracking and project progress monitoring.

During the project, I contributed to Agile planning, user interface development, application navigation, testing, debugging and project presentation activities.

The UniMarket project ran from July 2026 to September 2026. However, before the live website was submitted, I secured an Industry Placement at Motivity, which began on 1 October 2026. Because I needed to commit to the placement and could not manage both commitments simultaneously, I had to shift my focus to the professional opportunity.

Consequently, the UniMarket live website was not submitted as originally planned. This portfolio documents the work undertaken and the skills gained without claiming that the live website was submitted or that the entire project reached its intended final submission stage.

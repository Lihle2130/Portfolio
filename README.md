## Project Overview

UniMarket was developed as part of the Professional Practice Framework (PFP) module. The project was designed to address a common challenge experienced by students regarding the affordability and accessibility of academic resources.

The solution proposed by the team was a digital marketplace platform where students could buy, sell and exchange second-hand textbooks, study guides, calculators, notes and other educational materials. The objective was to create a cost-effective solution that would help students access resources while allowing others to sell materials they no longer needed.

The project followed Agile methodologies and utilized Trello for backlog management, sprint planning and project tracking.

---
